Learning map (new to agent systems)

Start here first, then run each interactive module below in order.

LangGraph
  • Use when one task has multiple steps, branching rules, or state transitions.
  • conditional-route: your code decides branch by explicit rules.
  • react-agent: model decides when and how to call tools in a loop.
A2A (Agent-to-Agent)
  • Use when one agent needs to ask another specialized agent over a protocol.
  • Think "service contract + remote execution" between agents.
  • This demo shows local A2A cards, message send, and full flow checks.
MCP (Model Context Protocol)
  • Use when an LLM should discover and invoke external tools in a standard way.
  • Think "tool registry + schema + invocation" across multiple servers.
  • This demo shows server discovery, tool listing, invocation, and full flow.
